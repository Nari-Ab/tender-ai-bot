Архитектура платформы Clean Architecture

TenderAI Sentinel построен по модульной архитектуре с полной изоляцией слоев парсинга, RAG и языковых моделей:

  • Feed Monitor & Scraper: Модуль мониторинга закупок ЕИС (44-ФЗ, 223-ФЗ) и Сбербанк-АСТ с фильтрацией по ОКПД2 и ценовым лимитам.
  • Document Parser: Извлечение текста из файлов спецификаций (PDF, DOCX, TXT) без потери структуры статей.
  • Semantic Chunker & Clause Retriever: Выделение критических условий (штрафы, пени, обеспечение, сроки, кабальные ограничения).
  • Multi-LLM Engine: Адаптеры к Сбер GigaChat API и Yandex Cloud Foundation Models с валидацией схемы Pydantic и автономным Mock-режимом.
  • Интерфейсы: Telegram-бот на aiogram 3 и REST API на FastAPI.
