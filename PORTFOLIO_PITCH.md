### 1. Проекты по автоматизации и ботам с нейросетями:

**Проект 1. «TenderAI Sentinel» — AI-ассистент мониторинга и скоринга тендеров (ЕИС / Сбербанк-АСТ)**
* **Ссылка на репозиторий:** `https://github.com/Nari-Ab/tender-ai-bot`
* **Что делает:** 
  1. Автоматический мониторинг закупок (44-ФЗ / 223-ФЗ) на торговых площадках (ЕИС, Сбербанк-АСТ) по фильтрам и ключевым словам.
  2. RAG-пайплайн и извлечение текста из документации (ТЗ, проект контракта в PDF / DOCX).
  3. Семантический аудит через LLM: выявление кабальных условий, завышенных штрафов/пеней (выше ПП РФ №1042), нереалистичных сроков поставки и скрытых требований (лицензии ФСБ/ФСТЭК, реестр Минпромторга).
  4. Формирование рекомендаций: бот в Telegram присылает структурированную выжимку и вердикт **«УЧАСТВОВАТЬ»** / **«ВЫСОКИЙ РИСК (НЕ УЧАСТВОВАТЬ)»**.
* **Моя роль:** Full-cycle разработчик (архитектура, интеграция LLM через API, RAG-чанкинг, разработка Telegram-бота на aiogram 3, REST API на FastAPI, докеризация).

**Проект 2. Мультимодальный AI-бот для генерации контента и объявлений**
* **Что делает:** Автоматизация создания визуалов и текстов для Avito/соцсетей по шаблонам компании. Принимает параметры товара/услуги, генерирует продающий текст с учётом tone of voice и формирует визуал, после чего планирует публикации по расписанию.
* **Моя роль:** Разработка логики промпт-инжиниринга, интеграция с API нейросетей, сохранение контекста диалога и планировщик задач (APScheduler).

### 2. С какими нейросетями работал через API:
* **GigaChat API (Сбер):** Большой практический опыт работы через официальный REST/SDK. Использовал для анализа русскоязычных юридических документов, работы со сложным контекстом ТЗ, классификации и генерации структурированных ответов (JSON-mode). Настроена работа с сертификатами Минцифры и OAuth-авторизацией.
* **YandexGPT (Yandex Cloud Foundation Models):** Опыт работы с Completion API и эмбеддингами (text-search/similarity) для RAG-сценариев и суммаризации текста.
* **OpenAI (GPT-4o, GPT-3.5-turbo), Anthropic Claude, локальные LLM через vLLM / Ollama** (Llama 3, Mistral, Saiga) — для задач с повышенными требованиями к приватности данных.
