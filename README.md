Продакшн-ориентированная система автоматического мониторинга государственных и коммерческих закупок (**44-ФЗ**, **223-ФЗ**) с разбором документации (ТЗ, проекты контрактов в форматах PDF/DOCX/TXT), RAG-поиском юридических рисков и генерацией рекомендаций **«УЧАСТВОВАТЬ / НЕ УЧАСТВОВАТЬ»** через отечественные языковые модели (**Сбер GigaChat**, **YandexGPT**).

---

## 🎯 Решаемые бизнес-задачи

1. **Ежедневный мониторинг площадок**: фильтрация закупок по ключевым словам, суммам (НМЦК), законам (44-ФЗ / 223-ФЗ) и площадкам (ЕИС Госзакупки, Сбербанк-АСТ, РТС-тендер, B2B-Center).
2. **Семантический разбор ТЗ и контрактов**: мгновенный парсинг объёмных документов (PDF/DOCX), извлечение условий оплаты, обеспечения, требований к сертификации (СТ-1, Минпромторг, ФСТЭК, ФСБ).
3. **Детекция юридических ловушек и кабальных условий**:
   - Неустойки и пени выше Постановления Правительства № 1042 (> 1% в день);
   - Нереалистичные сроки поставки (1–3 дня как признак «заточки» под аффилированного поставщика);
   - Требование залога вместо банковских гарантий.
4. **Формирование вердикта**: автоматическая выдача индекса риска (0–100) и структурированного отчета с рекомендацией прямо в Telegram.

## 🛠 Технологический стек

- **Язык**: Python 3.11+
- **Веб-фреймворк**: FastAPI, Pydantic v2, Uvicorn
- **Telegram Bot**: aiogram 3.x (FSM, Callback-хэндлеры, фильтры)
- **Нейросети & LLM API**:
  - `Sber GigaChat API` (OAuth2, официальный API, работа с контекстом ТЗ);
  - `YandexGPT API` (Yandex Cloud Foundation Models);
  - `Offline Heuristic Mock` (детерминированный офлайн-режим для тестов без затрат токенов).
- **RAG & Обработка документов**: `pypdf`, `python-docx`, семантический чанкинг с регулярными выражениями под нормы госзакупок.
- **Тестирование**: `pytest`, `pytest-asyncio` (100% покрытие ключевых модулей).
- **Контейнеризация**: Docker, Docker Compose.

## 🚀 Быстрый старт (Локально)

### 1. Клонирование и установка зависимостей
```bash
git clone <url-вашего-репозитория>
cd tender-ai-bot

# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте пример конфигурации:
```bash
cp .env.example .env
```
> По умолчанию установлен `LLM_PROVIDER=mock`, что позволяет мгновенно протестировать проект **без ввода ключей API**. Для подключения боевых моделей укажите `GIGACHAT_CREDENTIALS` или `YANDEX_API_KEY`.

### 3. Запуск тестов
```bash
pytest -v
```

### 4. Запуск API сервиса
```bash
uvicorn src.api.main:app --reload --port 8000
```
Документация Swagger UI будет доступна по адресу: `http://localhost:8000/docs`.

### 5. Запуск Telegram-бота
Укажите ваш токен от `@BotFather` в `.env`:
```bash
TELEGRAM_BOT_TOKEN="ваш_токен"
```
И запустите бота:
```bash
python -m src.bot.bot
```

## 📂 Структура репозитория

```text
.
├── Dockerfile                  # Докеризация сервиса
├── docker-compose.yml          # Сборка сервисов
├── requirements.txt            # Зависимости Python

│   ├── api/                    # FastAPI роуты (/health, /api/tenders, /api/analyze)
│   ├── bot/                    # Telegram бот на aiogram 3 (хэндлеры, клавиатуры)
│   ├── core/                   # Настройки, логирование, Pydantic модели
│   └── services/
│       ├── documents/          # Парсинг PDF/DOCX и семантический чанкинг

│       ├── parsers/            # Мониторинг реестров ЕИС и Сбербанк-АСТ
│       ├── rag/                # Извлечение риск-кластеров из ТЗ
│       └── scoring/            # Движок скоринга и принятия решений
```
